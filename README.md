# MemoryEcho（記憶迴響）

> 獨居長者跨世代生命故事共創與智慧陪伴系統

本專案實作 PDF 規格與 Figma 圖中的「長者端」與「青年端」雙軌介面：

1. **長者端：復古木質收音機**（依照 Figma 圖）
   - 按「說故事」→ 螢幕切換為「正在聆聽…「1970 年代，大稻埕…」」並亮起綠色指示燈。
   - 按「一鍵復原」→ 螢幕回到第一個畫面「阿姨，要不要聊聊年輕的事？」。
   - 音量旋鈕可以轉動（支援滑鼠點擊、滾輪或拖曳旋轉）。
2. **青年端：手機 App 畫面**
   - 顯示長者傳來的故事卡文字（大稻埕故事）。
   - 下方提供「點讚」和「語音回覆」兩個按鈕。

---

## 檔案結構

- `index.html`：長者端與青年端純靜態網頁結構。
- `css/style.css`：依據 Figma 視覺色票與版面之樣式表（純 CSS 繪製收音機，無外部圖片依賴）。
- `js/app.js`：純 Vanilla JavaScript 互動邏輯。
